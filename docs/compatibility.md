# Self-hosted server compatibility

This is the compatibility list inherited from upstream for Overleaf (ShareLaTeX) Community Edition images on [Docker Hub](https://hub.docker.com/r/sharelatex/sharelatex).

Checked entries are marked compatible in the upstream list; unchecked entries are not marked compatible there. This list does not establish support for every feature of this fork. History and collaboration features also depend on the server's available APIs and project permissions.
